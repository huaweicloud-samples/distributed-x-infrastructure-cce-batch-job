# 架构说明

## 概述

本实践展示了如何使用 Terraform 在华为云上部署容器化定时批量计算作业。通过 CCE（云容器引擎）集群运行 Kubernetes CronJob，实现容器镜像的自动构建推送、定时触发执行和日志收集。

## 组件说明

| 组件 | 华为云服务 | 说明 |
|------|-----------|------|
| 容器镜像仓库 | SWR（SoftWare Repository for Container） | 存储构建好的容器镜像，供 CCE 拉取 |
| 容器集群 | CCE（Cloud Container Engine） | 提供 Kubernetes 运行环境，承载批量作业容器 |
| 定时作业 | K8s CronJob | 按 cron 表达式定时触发容器化作业执行 |
| 日志收集 | LTS（Log Tank Service） | 收集作业执行日志，支持按天保留 |
| 网络 | VPC + Subnet + Security Group | 为 CCE 集群提供隔离的网络环境 |

## 工作流程

1. **镜像构建与推送**：Terraform 使用 Docker Provider 构建容器镜像并推送到 SWR
2. **集群创建**：Terraform 创建 CCE 集群和节点池
3. **定时作业部署**：Terraform 通过 Kubernetes Provider 在 CCE 集群上创建 CronJob
4. **定时执行**：CronJob 按 cron 表达式（默认每天 20:00）自动创建 Job Pod 执行容器化作业
5. **日志收集**：作业容器的标准输出通过 CCE 日志采集写入 LTS

## 资源规格说明

| 资源 | 默认规格 | 可调整变量 |
|------|---------|-----------|
| CCE 集群 | cce.s1.small | — |
| CCE 节点 | s6.large.2 × 1 | `node_flavor` / `node_count` |
| 作业 CPU | 250m (0.25 核) | `job_vcpu` |
| 作业内存 | 512Mi | `job_memory` |
| 日志保留 | 30 天 | `log_retention_in_days` |
